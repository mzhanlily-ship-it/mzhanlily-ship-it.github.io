Which supplier fits regular orders, event orders and backup supply—and when should operational judgement override the top score?

The highest score is only part of the decision

Unipak / Pack & Send ranks first for regular supply (0.2667). Univest leads for event supply (0.2263), where the cost priority is higher.

For backup supply, Pack & Send also scores highest (0.3029). However, the report selects Smartfox (0.2766) to provide an alternative source. Choosing the same primary source as backup would not necessarily protect against a supplier-level failure. This is a distinction between numerical ranking and a sourcing policy.

How the weighting works

The scripts normalise each pairwise-matrix column, average across each row, then normalise the resulting vector. The selected excerpt exposes that calculation without presenting the wider team simulation as my individual work.

# Normalisation function from the submitted supplier evaluation scripts.
# A must be a positive pairwise comparison matrix.
ahp_weights <- function(A) {
  A <- as.matrix(A)
  A_norm <- sweep(A, 2, colSums(A), "/")
  w <- rowMeans(A_norm)
  w / sum(w)
}

Limits and a useful next test

Scores depend on judgement-based ratings and the source inputs. The scripts substitute a positive value for some zero ordering costs to enable pairwise comparisons; that choice can affect cost rankings. The team report states that AHP consistency ratios were checked, but this public excerpt neither reproduces nor independently validates those checks. A reproducible consistency audit and systematic weight sensitivity test would strengthen the analysis.

These are academic evaluation outputs, not current verified supplier quotations or procurement advice. The R excerpt has not been executed in this portfolio environment.
